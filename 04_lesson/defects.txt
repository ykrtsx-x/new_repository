
                    ОТЧЕТ О ДЕФЕКТАХ (BUG REPORT)
                    Класс StringUtils

ДЕФЕКТ #1

Название: Отсутствует обработка None в методе capitalize()
Серьезность: Major
Приоритет: High
Компонент: StringUtils.capitalize()

Описание:
Метод capitalize() не обрабатывает входное значение None, что приводит к 
возникновению исключения AttributeError.

Шаги для воспроизведения:
1. Создать экземпляр класса StringUtils
2. Вызвать метод capitalize() с аргументом None
3. utils.capitalize(None)

Ожидаемый результат:
Должна возвращаться пустая строка "" или должно быть обработано исключение

Фактический результат:
AttributeError: 'NoneType' object has no attribute 'capitalize'

Влияние на продукт:
При передаче None в метод приложение падает с необработанным исключением

ДЕФЕКТ #4

Название: Отсутствует обработка None в методах contains(), delete_symbol(), 
         starts_with(), end_with()
Серьезность: Major
Приоритет: High
Компонент: StringUtils (несколько методов)

Описание:
Методы contains(), delete_symbol(), starts_with(), end_with() не обрабатывают 
входное значение None для первого аргумента (строки), что приводит к 
возникновению исключения AttributeError.

Шаги для воспроизведения:
1. Создать экземпляр класса StringUtils
2. Вызвать любой из методов с None в качестве первого аргумента
3. utils.contains(None, "a")

Ожидаемый результат:
Должен возвращаться False или должно быть обработано исключение

Фактический результат:
AttributeError: 'NoneType' object has no attribute 'contains' (или другой метод)

Влияние на продукт:
При передаче None в методы приложение падает с необработанным исключением



ДЕФЕКТ #5

Название: Непоследовательное поведение метода is_empty() с None
Серьезность: Minor
Приоритет: Medium
Компонент: StringUtils.is_empty()

Описание:
Метод is_empty() обрабатывает None, но возвращает True, что может быть 
неожиданным поведением. По документации метод должен проверять пустую строку 
или строку только из пробелов. None не является строкой.

Шаги для воспроизведения:
1. Создать экземпляр класса StringUtils
2. Вызвать метод is_empty() с аргументом None
3. utils.is_empty(None)

Ожидаемый результат:
Должно быть исключение TypeError или False

Фактический результат:
True

Влияние на продукт:
Потенциально некорректная логика при проверке None как пустой строки



ДЕФЕКТ #6

Название: Отсутствует обработка None для параметра joiner в list_to_string()
Серьезность: Minor
Приоритет: Medium
Компонент: StringUtils.list_to_string()

Описание:
Метод list_to_string() не обрабатывает значение None для параметра joiner,
что приводит к использованию None как разделителя и вызывает ошибку.

Шаги для воспроизведения:
1. Создать экземпляр класса StringUtils
2. Вызвать метод list_to_string() с None в качестве разделителя
3. utils.list_to_string([1,2,3], None)

Ожидаемый результат:
Должен использоваться разделитель по умолчанию ", " или исключение

Фактический результат:
TypeError: sequence item 0: expected str instance, int found (из-за join(None))

Влияние на продукт:
При передаче None в качестве разделителя приложение падает с ошибкой
